# 本地操作界面

这是供队员演示和运行当前正式M2基线的本机网页界面，不需要安装前端框架，也不会把比赛文件上传到互联网。

## 启动

在项目根目录执行：

```bash
.venv/bin/python web_app.py
```

然后在同一台电脑的浏览器打开 `http://127.0.0.1:8765`。按 `Ctrl+C` 关闭界面。

## 使用

1. 上传卫星TLE文件，格式为每颗卫星三行：名称、TLE第1行、TLE第2行。
2. 上传站点文本，每行采用 `编号：经度, 纬度, 海拔(m)` 格式。
3. 选择全部10,000个目标，或选择前1,000个目标作快速试运行。
4. 点击“检查文件”。系统校验结构和SHA-256；只有与当前正式D窗口完全一致的输入才允许继续。
5. 选择调度策略并点击“生成调度并验收”。完成后页面显示覆盖、得分、观测数、利用率和独立裁判结论，可下载调度CSV及裁判明细CSV。

## 当前支持范围

当前运行入口使用正式规划区间 **2026-08-01 00:00至2026-08-07 00:00 UTC**、本机已配置的优先级文件和经过哈希锁定的D受光窗口。界面不会因为上传了不同TLE或站点文件而沿用旧窗口；输入SHA-256不一致时会停止并要求先为新输入重算、验证M1 A/B/C/D缓存。这样可以避免生成貌似成功、实际引用过期窗口的结果。

界面是本地演示入口，不是通用窗口生成器。它只监听 `127.0.0.1`，作业结果写到被Git忽略的 `output/ui_runs/`。需要正式使用完整10,000目标时，请确认本机D缓存、状态表、优先级文件和DE421星历均已按项目清单准备好。
